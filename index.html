▶ runbrowser

Browser infrastructure for developers and agents.

Hosted Chromium you connect to over WebSocket. Drop-in for Playwright and Puppeteer. Stable sessions for AI agents. Built without the surprise bills.

How it works

// Same code, different endpoint.
// No fleet to run. No Chrome to babysit.

import { chromium } from 'playwright'

const browser = await chromium.connectOverCDP(
  'wss://api.runbrowser.dev?token=YOUR_TOKEN'
)
const page = await browser.newPage()
await page.goto('https://example.com')
await page.screenshot({ path: 'out.png' })
await browser.close()
