01

one line changes

connect.tswss://connect.runbrowser.dev
// Same code. Different endpoint.
// No fleet to run, no Chrome to babysit.

import { chromium } from 'playwright'

const browser = await chromium.connectOverCDP(
  'wss://connect.runbrowser.dev?token=YOUR_TOKEN'
)
const page = await browser.newPage()
await page.goto('https://example.com')
await page.screenshot({ path: 'out.png' })
await browser.close()

That's the whole integration — standard CDP, nothing to rewrite. Prefer a typed client for the REST endpoints? npm install runbrowser or pip install runbrowser; neither wraps Playwright, and neither has runtime dependencies. SDKs →

02

what's in the box

Live session viewer

Watch any run in real time. Hand a teammate a signed, expiring link that carries no API key — safe to paste in a ticket. Nobody else advertises this.

● livessn_a1f9c3 · streaming

Structured /extract

A URL plus a JSON Schema in, validated JSON out. It renders the page first, retries on a schema miss, and 422s rather than handing you malformed data.

MCP server, built in

Nine browser tools for Claude, Cursor and anything that speaks MCP — with descriptions that steer the model to the cheap path first. No integration code.

Honest by default

We flag a bot wall instead of returning the interstitial as content. CAPTCHA solving is bring-your-own-key at your provider's wholesale price — no markup, no "evasion-as-a-service".

EU-hosted, no lock-in

Browsers and session data stay inside the European Union. You connect over standard CDP, so there's no proprietary SDK to rewrite if you ever leave.

Stable sessions

The browser stays alive between connects — in-memory SPA state and open tabs, not just cookies. Survives our redeploys too.

A REST surface too

screenshot, pdf, scrape, fetch, search, function, map, crawl, download — for when you don't want to drive a browser at all.

Managed proxy pools

Pick a country and the browser's timezone and language follow the exit IP — no New-York clock on a Frankfurt address. Or bring your own, at wholesale.
